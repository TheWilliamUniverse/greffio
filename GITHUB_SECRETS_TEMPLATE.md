# GitHub Secrets Template (Actions)

Configurer ces secrets dans **Settings > Secrets and variables > Actions**.

- `OPENAI_API_KEY`
- `DATABASE_URL`
- `JWT_SECRET`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SUPABASE_STORAGE_BUCKET`
- `DOCUMENT_STORAGE_DRIVER`
- `MOLLIE_API_KEY`
- `MOLLIE_WEBHOOK_URL`
- `INSEE_API_TOKEN` (optionnel)
- `PAPPERS_API_TOKEN` (optionnel)
- `SENTRY_DSN_BACKEND` (optionnel)
- `SENTRY_DSN_FRONTEND` (optionnel)

## Security hardening to enable

- GitHub Advanced Security: **Secret Scanning = ON**
- Push Protection: **ON**
