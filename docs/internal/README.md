# Documentation interne Greffio (VPS)

Ces fichiers sont déployés sur le VPS avec le backend :

```
/opt/greffio/docs/internal/
```

Ils **ne sont pas servis** par le frontend public Hostinger ni par Nginx côté site client. Référence réservée à l’équipe Greffio / William Establishments.

| Fichier | Description |
|---------|-------------|
| `GREFFIO-MASTER-ARCHITECTURE-ET-HISTORIQUE.md` | Architecture complète, historique des demandes, infra, modules métier |

Pour un audit IA **sans secrets**, utiliser plutôt :

```
docs/GREFFIO-AUDIT-CONTEXT-IA.md
```

(dans le repo, partageable avec une IA pour propositions features admin/pro)
